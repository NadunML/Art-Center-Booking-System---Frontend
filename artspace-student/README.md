# ArtSpace Student Portal — UI Starter

Responsive React/Vite/Tailwind v4 demonstration frontend. **All bookings, events, notifications, and user details are mock data.** No authentication, real reservations, emails, or backend integration is included.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:5173/ .

If adding these files to an existing Vite project, back up the original `src`, `index.html`, and `vite.config.js` before replacing. The package versions here are compatible starting points; `npm install` resolves dependencies.
